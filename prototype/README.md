# Dlicom Racers Asset Garage

Run from this folder:

```powershell
npm run start
```

Then open `http://127.0.0.1:4173/prototype/`.

The static development viewer imports Three.js r160 from its pinned CDN import map and loads the actual sibling GLBs from `../assets/`. It is intentionally only an asset-validation surface: choose standing, kart, or seated modes; orbit the camera; use the sliders to test wheel/steering pivots; and click a clip to inspect Guatam's exported animations.
